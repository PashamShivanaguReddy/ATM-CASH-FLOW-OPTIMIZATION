# ATM Cash Flow Frontend

React, TypeScript, Vite, and Tailwind CSS foundation for the ATM Cash Flow Optimization System.

## Development

```sh
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in a local `.env` file to point the Axios client at the API gateway. The default is `/api`; no business endpoints or authentication behavior are assumed in this phase.

## Production build

```sh
npm run build
npm run preview
```
